# B 板 CSI→DSI 中继 —— 状态交接（2026-10-29 04:05）

## 一、目标（已与你确认）

**B 板的 DSI 输出要"等价于摄像头输入"，让 A 板看起来就像直接插着 SC500 摄像头。**
但实现**不走透明转发**，必须走：

```
CSI 接收 → 包解析 → 行缓冲 → 重新打包 CSI-2 → DSI 发出
                      ↑
              以后 CNN 识别/OSD 就插在这里
```

透明转发虽然简单，但只搬字节、没有像素级的行缓冲，无法做识别——所以放弃。

## 二、当前架构与代码

```
摄像头
  │ MIPI CSI-2, 2592x1944 RAW10, 2 lane
  ▼
DPHY0 RX（厂商封装）
  ▼
csi2_rx_parse.v     抓包头、搬载荷、产出行边界
  │  令牌：00=载荷  01=帧起  10=行结束(带WC)  11=帧尾
  ▼
csi2_ptr_fifo.v     18bit 异步 FIFO（2048 深）
  ▼
csi2_tx_packet.v    行缓冲乒乓 + 打包 FS/长包/FE
  ▼
DPHY1 TX（厂商封装，350Mbps/lane）
  ▼
到 A 板
```

**行缓冲就是未来 CNN 的接入点**：`csi2_tx_packet` 的 `mem` 里是完整的
2592×1944 像素流，每行 3240 字节。

   ISP 不输出）。已加 `assign S_ISP_O_tready = 1'b1;`（下游无背压）。
2. **加了 4 颗调试灯**（D10/E10/C6/D6），当前映射：
   - LED1 = `S_csi_frame_start`（收到帧起）
   - LED2 = `S_csi_frame_end`（收到帧尾）
