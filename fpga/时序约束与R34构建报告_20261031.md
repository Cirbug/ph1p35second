## 结果对比

R30 仍把 DDR user clock 到 MIPI RX 的跨域路径按同步路径检查，报告为 `SWNS -3.312 ns`、`HWNS -3.511 ns`。R33 在主 Tcl 中尝试临时路径约束，证明对象可收集，但正式报告仍保留跨域路径，且最终 STA 未通过。

R34 的正式 SDC 时钟组生效后，最终报告的 `Inter clock domain timing` 不再包含相机 RX/TX 与 DDR user clock 的普通跨域组；剩余检查为 DDR IP 自身合法的同步路径，且全部通过。

## 板级串口验证

日期：2026-10-31。用户确认已下载本次 bit 后，通过 COM16（115200、8N1）连续读取两段，共约 12 秒、103 行。主要字段在采样期间保持不变：

```text
C=1 W=0CA8 D=2B ... F=0001 ... T=0002
FS=0000 FE=0000 RD=0000 RI=0000 IW=0000 RE=0000 RXE=0
SO=0438 OW=0960 SE=0 TP=0000 TL=0000 TB=00000000 TW=0000 TE=0
```

- `W=0CA8`、`D=2B`、`H0=2BA8`、`H1=0C3B` 与 RAW10 行包头相符，`V` 持续变化，说明 B 板 MIPI RX 有数据活动。
- 缩放统计 `SO=0438`、`OW=0960`、`SE=0` 分别表示 1080 行、每行 2400 字节、未报告格式错误；这验证到裁剪/缩放器输出统计，不能单独证明 DDR 回读正确。
- `FS/FE/RD=0` 表示 RX 解析统计没有看到显式帧开始/结束短包。当前 RTL 还会按配置的 1944 条 RAW10 行推断输入帧尾，因此缩放器统计仍可能正常更新。
- `F=0001` 是 TX 帧开始令牌计数；`T=0002` 是 TX 实际 HS 输出拍数。两拍正好对应 4 字节 CSI-2 FS 短包。`TP/TL/TB/TW` 仍为 0，且采样期间不变，板上没有观察到后续图像行或完整 TX 帧。
- COM9 在单独 4 秒只读采样中没有收到串口字节；当前无法据此确认 A 板接收状态。

结论：RX 和裁剪/缩放统计有活动，但 B 到 A 的 CSI TX 视频尚未跑通。仅凭当前 UART 字段还不能在 DDR 帧提交/读回、relay token FIFO 和 DPHY TX ready/clock 之间定位阻塞点。下一版诊断应增加 DDR 初始化/提交/读请求/读返回计数、读侧输出 word/line/frame 计数、relay FIFO 水位或溢出、TX ready 与 DPHY lock 状态；随后以 RAM 下载复测。当前板级视频验证不通过。
