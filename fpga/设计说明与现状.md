> 工程：`fpga_11/ph1p35second/fpga`
> 器件：Anlogic PH1P35MDG324（-3）
> 位流：`fpga_prj.bit`（2026-10-28 22:20:03）
> 状态：**软件侧完成并通过全部仿真；硬件链路待实测**

---

## 一、功能

把 B 板（MLKPAI-F02）摄像头画面，原样转到 A 板（HX1P35A）显示。

```
SC500CS 摄像头
   │ 2 lane MIPI, RAW10, 1928x1088@30fps
   ▼
[CSI 座] ──► DPHY0 RX ──► csi2_rx_parse ──► 令牌打包
                                              │
                                      csi2_ptr_fifo（异步，跨时钟域）
                                              │
                              令牌解包 ──► csi2_tx_packet ──► DPHY1 TX
                                                                    │
                                             6 根线（CK+D0+D1+GND）│
                                                                    ▼
                                                          [A 板 J9] → HDMI
```

**设计要点：透明中继。** 不解析像素、不做色彩处理，只把摄像头发出的
CSI-2 包拆开、换一个"信封"重发。所以 A 板收到的数据与直接接摄像头完全等价，
A 板侧无需任何改动。

```

uisrc/02_sim/              11 个 testbench + 2 个 PHY 桩
tools/                     并行 CRC 生成器与 Python 自检

settings.cfg + run_flow_fixhold.tcl   TD 命令行流程
```

## 四、开发过程中修掉的 6 个缺陷

这些都不是"编译不过"级别的，而是会**静默让画面出不来或花屏**的问题。

| # | 缺陷 | 后果 | 怎么发现的 |
|---|---|---|---|
| 1 | ECC 校验表 bit8/bit18 syndrome 碰撞 | 包头校验失效 | 自写 testbench 唯一性检查 |
| 2 | 并行 CRC 字节序反了 | CRC 全错 | Python 20000 组随机向量自检 |
| 3 | 异步 FIFO 组合逻辑环 | 综合直接失败 | TD 报 SYN-5033 |
| 4 | 行缓冲装不下 1928 宽 | 画面撕裂 | 解码摄像头寄存器表算出真实分辨率 |
| 5 | 摄像头 PWDNB 极性反了 | **完全黑屏，无任何提示** | 逐行对照厂商例程 |
| 6 | 乒乓 bank 发送期间跳变 | 整行数据静默污染 | 重新推导状态机（退回旧逻辑可复现 1196 项失败）|

> 第 5、6 两个最危险：现象都是"没图"或"偶发花屏"，且不报错。
> 第 6 个还写了专门的回归测试 `tb_csi2_bank_switch` 钉住。

## 五、怎么重新出流

不需要打开 GUI：

```powershell
cd D:\BaiduNetdiskDownload\02_F02_FC02_PH1P35\fpga_11\ph1p35second\fpga
D:\TD\bin\td_commands_prompt.exe D:/TD/doc/scripts/DefaultFlow.tcl
```

约 1 分钟出 `fpga_prj.bit`，日志在 `td_flow.log`。

**注意**：`settings.cfg` 里必须保留 `set alRun syn_1` 和
`set arr_filter off` / `set drHoldFix off`，否则 TD 的 CLI 流程会去找
`.prj` 文件或报 `can't read "arr_filter"`。

## 七、已知限制

1. **曝光需手动调**。`ae_set` 已接入，默认 `AE=3000/AG=60`；按键
   N2/J14 可加减曝光。不按键时不写 AE 寄存器。
2. **只支持 2 lane**。`csi2_rx_parse` 假设包头占 2 拍（4 字节）。
3. **WC 必须为偶数**（RAW10 1928 宽 → 2410，满足）。奇数会置位 `wc_err`。
4. **PLL 参数写死在 `uisrc/03_ip/pll/pll.v`**。若在 TD 界面重新生成 PLL
   会退回单路 200MHz，需按 100M/24M 重配。
5. `pll_test.v` 已从工程移除（文件仍在目录里，不参与编译）。
