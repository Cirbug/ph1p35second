# PH1P35 B 板裁剪后写入 DDR 改造报告（R25）

日期：2026-10-31  
工程：`D:\2026fpga\ph1p35second_r2_jop13\fpga`  
目标器件：PH1P35MDG324

## 目标链路

传感器仍输出 `2592×1944 RAW10`。B 板在 RX 时钟域先执行现有 RAW10 水平裁剪、缩放和垂直裁剪，形成 `1920×1080 RAW10`；三帧 DDR 缓存保存这一路处理后的图像。DDR 读侧把同一帧并行送往 A 板 CSI-2 relay 和本地 CNN，CNN 从 `1920×1080` 缩放/二值化到 `320×180`。

| 阶段 | 尺寸与格式 |
|---|---|
| 摄像头输入 | `2592×1944 RAW10` |
| B 板 DDR 写入 | `1920×1080 RAW10`，每行 2400 payload bytes |
| A 板输出 | `1920×1080 RAW10`，CSI-2 DT `0x2B` |
| CNN 输入 | 与 A 板相同的 DDR 读侧 RAW10 帧 |
| CNN 预处理输出 | `320×180` 二值灰度像素 |

RAW10 的每个像素占 10 bit，DDR 接口每个逻辑样本按 16 bit 缓存并以 128-bit beat 写入。处理后每帧为 `1,296,000` 个 16-bit 样本、`162,000` 个 DDR beat，三帧地址跨度为 `3,888,000` 个 16-bit 地址单位，payload 容量为 `7,776,000` 字节（约 7.42 MiB）。实际 DDR 地址单位及板级吞吐仍需硬件验证。

## RTL 改动

- 将 `csi2_raw10_scale_crop` 放到 DDR 输入端，输入来自 CSI parser；裁剪参数保持 `SRC=2592×1944`、水平去边 `8` 像素、缩放到 `1920×1440`、上下各裁 `180` 行，最终输出 `1920×1080`。
- `ddr_triple_frame_cache` 改为按处理后帧的行字数、总字数、行数和 bank 地址跨度配置。
- CNN resize 的源尺寸改为 `1920×1080`，输入来自 DDR 缓存读侧；A 板 relay 也直接取同一 DDR 读流。
- 输出行包 WC 保持 `2400` bytes；裁剪模块行数、WC 和格式错误统计改在 RX 时钟域采集。

## 仿真与构建

- Icarus `tb_csi2_raw10_scale_crop`：通过；输出 160 个 RAW10 word、16 行、2 个 FS 和 2 个 FE。
- Icarus `tb_ddr_triple_frame_cache`：通过；验证 DDR 帧写读、word 顺序、行标记重建和不完整帧中止。
- Icarus `tb_csi2_crop_ddr_fanout`：通过；验证 320 个缩放/裁剪 word 写入并从 DDR 按序读回，CNN 得到 32 个测试像素，错误标志为 0。该 testbench 没有实例化 A 板 TX FIFO/CSI-2 发射器；A 板路径目前由顶层静态连线检查确认，尚无该路径的联合仿真或板测证据。
- TD `v6.2.1_Engineer_6.2.168.116` 完成 R25 布局布线，STA 覆盖率 97.61%，结果为 `SWNS=-3.705 ns`、`STNS=-134.732 ns`、`HWNS=-3.510 ns`、`HTNS=-49.387 ns`，时序不通过。

### 资源增量来源

以下是三个独立版本的 `final.area` 汇总，器件相同；版本间 RTL 有其他改动，适合定位增量出现在哪一版，不应当作单模块隔离实验：

| 版本 | Slice | LUT6 | ERAM20K | DRAM LUT |
|---|---:|---:|---:|---:|
| R23 三帧 DDR | `9287/21216`（43.77%） | `8776/21216`（41.37%） | `5/108` | `304` |
| R24 原始帧先写 DDR | `13540/21216`（63.82%） | `13060/21216`（61.56%） | `9/108` | `2992` |
| R25 裁剪后写 DDR | `13972/21216`（65.86%） | `13536/21216`（63.80%） | `9/108` | `2992` |

R23 到 R24 的主要增量来自新增/扩大的 TX 中转队列：`u_relay_tx_token_fifo` 使用 1536 个 DRAM LUT，`u_tx_packet` 使用 1024 个，合计 2560 个，占 R24/R25 总 DRAM LUT 的约 85.6%；R23 中这两个深队列尚未进入当前 relay 数据路径。图像帧数据存放在外部 DDR，以上 DRAM LUT 是 FPGA 片上分布式 FIFO/缓冲，不是整帧 DDR 像素存储。

裁剪缩放器在 R23、R24 已存在，R25 是把它从 DDR 读侧移到 DDR 写侧。R24 到 R25 的整机增量为 432 slices、476 LUT6；ERAM20K 和 DRAM LUT 数量不变。因此 65.86% 的绝大部分不是这次移动裁剪器造成的，裁剪前写 DDR 本身只带来约 2.04 个百分点的 slice 增量。

时序报告中的负路径包括裁剪器 `src_group_count` 到推断 RAM 读地址的 RX 同域 setup 路径，以及 DDR 用户时钟到 MIPI RX 时钟域的缓存跨域路径。需要先逐条核查逻辑路径、CDC 同步边界和时钟约束，再做针对性优化；不可为了得到 bit 直接放宽/屏蔽这些路径。

## 版本边界

R25 使用独立构建脚本 `tools/build_csi_cnn_r2_maincam_r25_crop_ddr.tcl` 和独立 bank 输出目录。R24 文件与既有工程修改保留，不清理、不覆盖。当前 R25 是“裁剪/缩放 -> 三帧 DDR -> relay/CNN”的 RTL 实验版本，不是可烧录版本；R24 保持原始帧先写 DDR 的独立实验文件与输出目录。
