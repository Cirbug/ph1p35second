## Finding

The CNN result UART path and the VOFA binary image-dump UART path share J3.
`CNN_VOFA_IMAGE_DUMP` defaulted to `1`, so the default top-level output selected
the binary image stream and bypassed human-readable `D,...` and `FRAME_DONE,...`
records. The parameter default is now `0`; setting it to `1` still enables the
optional VOFA image diagnostic path.

The detector and its inputs were not changed in this build. The detector still
consumes the 320x180 resized/binarized stream read from the DDR cache. Board
recognition correctness remains unverified until R46 is RAM-loaded and tested.

## Board check after RAM load

Use J3 at `115200 8N1`. A completed zero-detection frame should print
`FRAME_DONE,00`; a frame with candidates prints one `D,x,y,w,h,class` line per
candidate followed by `FRAME_DONE,NN`. If these lines appear, the detector frame
completion and result-UART route are active. If no line appears, continue with
frame input/DDR cache and detector busy/frame-toggle diagnostics. Correct class
labels and boxes still need comparison against a known image.
